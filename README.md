# Todo Camionetas — Sistema de Gestión

Sistema web de venta e inventario para Todo Camionetas (repuestos y accesorios para autos y camionetas).

Ver [`CLAUDE.md`](./CLAUDE.md) para el contexto completo del negocio, arquitectura y decisiones de diseño.

## Cómo correrlo localmente

```
npm install
npm run dev
```

Necesitas un archivo `.env.local` en la raíz con las claves de Firebase (pide una copia si no la tienes — nunca se sube a GitHub).
