# Datos privados

Esta carpeta es **local, no se sube a GitHub** (está en `.gitignore`).

Aquí va el archivo Excel real del inventario (`Excel real.xlsx` o el nombre que tenga),
y cualquier otro archivo con datos reales del negocio (precios, costos, clientes, etc).

El script de importación (`scripts/importar-excel.js`) lee el Excel desde aquí.
